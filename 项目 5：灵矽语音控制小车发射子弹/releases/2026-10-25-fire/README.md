# 单次蓄力重炮发布包：2026-10-25-fire

源码已同步到发布仓库的 linx-esp32/ 与 stm32_motion/。历史发布包保留，请按同一发布包内的固件、页面与证书配套烧录。

## 本次更新

- 网页新增“发射一次 · 蓄力重炮”按钮，仅取得遥控权后可用；请求在输出锁内保留当前四个运动位并置 bit4，经原 AA55 状态帧转发，不关闭持续收听，也不等待云端平台就绪。
- STM32 收到 bit4=1 后播放一次 6.4 秒灯效：三轮蓄力、反向逐颗发射、全灭结束；PB0 蜂鸣器发射时双响。忙时忽略重复发射，方向/停止/fire=off 不中断灯效。
- “开始收听”不再被平台就绪、安全上下文或录音能力在点击前禁用，取得遥控权后即可点击并由浏览器弹出麦克风授权；点击后校验录音能力，弹窗期间提示“正在申请麦克风权限”，失败原因写入状态栏。
- 网页确认只代表 ESP32 已处理转发，不新增 STM32 ACK 或灯效完成回传。

## 使用

手机连接小车热点，在完整浏览器打开 https://192.168.4.1/ 。首次使用安装并信任 certificates/car-root-ca.cer；该公开证书与本包固件对应。iPhone 还需开启根证书完全信任。重新生成证书的固件需要匹配的新根证书。

配网地址为 http://192.168.4.1/ 。热点不提供互联网转发，ESP32 需通过已配置的路由器访问灵矽。更新后断开再连接手机热点，清除此前 DNS 重定向影响。

## 烧录

ESP32-S3，16 MB Flash；保留镜像自身的 flash mode/frequency（keep）。

| 地址 | 文件 |
| --- | --- |
| 0x0 | esp32s3/bootloader.bin |
| 0x8000 | esp32s3/partitions.bin |
| 0xd000 | esp32s3/ota_data_initial.bin |
| 0x20000 | esp32s3/firmware.bin |
| 0x800000 | esp32s3/generated_assets.bin |

STM32F103：stm32f103/firmware.bin 烧录到 0x08000000，或使用同目录 HEX。
接线沿用上一版：ESP32 UART1 TX17→STM32 PA10、RX21←PA9、共地；INMP441 BCLK5、WS4、SD6，左声道；蜂鸣器 PB0 高有效；灯排 PB10、PB1、PA7～PA0 低有效。
