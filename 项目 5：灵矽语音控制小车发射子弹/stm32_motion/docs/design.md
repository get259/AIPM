# 移动控制设计

## 已确认

- 新建独立本地仓库，使用标准 PlatformIO 结构。
- 参考 STM32F103C8 原有电机控制，删除循迹、避障和按键启动流程。
- 动作持续到下一条有效状态，不使用阻塞延时或动作超时。
- 对接现有 ESP32：115200 / 8N1，AA 55 STATE CRC8。
- ESP32 GPIO17 TX → STM32 PA10 RX，GPIO21 RX ← PA9 TX，共地。
- 左转、右转表示前进同时转向，不采用原地旋转。
- 两侧均向前输出，内侧降低占空比；不再采用内侧停止转弯。

## 组件

USART1 RX 中断 → 127 字节有效容量环形队列 → 主循环 → 四字节滑动窗口校验 → 运动映射 → 四路 PWM。
协议和运动映射不依赖硬件，可用实际 ARM 编译结果在模拟器中测试。
TIM4 四路同一更新事件生效，避免四个比较寄存器更新期间跨周期出现不一致输出。

## 错误处理与边界

- 非法或未收齐的帧不更新动作，不把串口噪声解释为停止指令。
- 接收错误、溢出重置队列和解析器，后续有效帧可恢复。
- 保留位非零拒绝；LED 位不影响运动。
- 未增加 ACK、周期回传、超时停车、看门狗或电机换向延时。
- 沿用参考程序 70% PWM 作为初始配置；物理速度、方向和晶振仍需实测。
- 内侧占空比比例暂设为外侧的 50%，通过 CAR_TURN_INNER_PERCENT 调节；这是初始调试值，尚未实测。
- 当前组合规则：前进叠加转向与单独转向一致；后退叠加转向时两侧均倒转，并交换内外侧以保持车头转向含义。前后同时开启或左右同时开启则停止，这是实现中采用的冲突处理规则。
