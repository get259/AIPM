# 网页遥控与浏览器语音接入设计

日期：2026-10-24
状态：初版设计历史记录。后续已改为独立遥控页、点击持续收听和独立云端发送任务；当前实现与使用方式以 `docs/web-remote.md` 为准。

## 1. 已确认需求

- 主工程为 `linx-esp32`，复用已有 Wi-Fi 配网、灵矽激活网页及 ESP-IDF 基础设施。
- 遥控页面同时适配安卓、iPhone 和电脑浏览器；桌面 Chrome 为明确目标，手机端分别验证 Chrome 和 Safari。
- 所有设备都显示前进、后退、左转、右转、停止五个按钮；电脑另外支持 WASD、方向键及空格停止。
- 页面有遥控开关。开启后独占接管，暂停 INMP441 采集上传，仅接受网页方向按钮及浏览器语音；关闭后先停止、清理网页音频，再恢复 INMP441。
- 方向按钮按住移动、松开停止；语音按钮按住说话、松开提交。
- 热点每次上电开启，已有 Wi-Fi 配置、联网成功和平台激活完成均不关闭热点。
- 用户接受首次在手机和电脑上安装并信任本地证书，以支持 HTTPS 网页直接录音。

## 2. 当前代码与需要替换的行为

- `third_party/esp-wifi-connect/assets/wifi_configuration.html` 与 `wifi_configuration_done.html` 为现有配网和激活页面。
- `WifiConfigurationAp` 使用 HTTP，固定热点地址为 `192.168.4.1`；目前固件未启用 HTTP WebSocket 和 HTTPS 服务端。
- `WifiManager::StartConfigAp()` 会停 STA；`StartStation()` 仅在激活页面模式保留已有 AP。普通已配网启动不会主动开 AP。
- 激活成功页请求 `/exit`，`WifiManager::SetActivationStatus()` 还有五秒关闭 AP 的任务。常开模式必须同时取消这两个退出来源，不能只改页面。
- `AudioService` 已使用 16 kHz、单声道、60 ms Opus 编码，每帧 960 个 PCM16 样本、1920 字节。可复用编码和平台发送流程。
- `CarController` 目前只接 AI 回复，实际 UART 输出集中在私有 `ApplyState()`；网页按键应调用受控的新入口，不复制帧编码和 UART 代码。
- 当前 TTS 事件主要依靠连接级 `session_id` 识别，不能只用本地开关变量区分同连接内的旧 AI 回复。

## 3. 页面与用户操作

保留现有配网和激活功能，增加独立遥控页面及入口。页面资源全部存入固件，不依赖公网脚本、字体或 CDN。

- 顶部显示网络、平台连接、遥控开关和当前控制来源。
- 中间为方向键布局，中央为醒目的停止按钮；手机竖屏和电脑窗口都能完整操作。
- 底部为按住说话、录音状态和错误提示。未取得麦克风权限时方向按钮仍可使用。
- 页面加载只读取设备状态，不自动打开遥控开关。设备重启后默认关闭遥控，沿用 INMP441。
- 使用 Pointer Events 统一鼠标、触摸；处理 pointerup、pointercancel、丢失指针捕获、窗口失焦、页面隐藏和键盘释放。仍有连接时立即发送停止与录音结束/取消，不依赖页面卸载请求必然送达。
- 阻止方向键滚动页面和长按选择；文本输入框内不拦截键盘操作。重复 keydown 不反复提交同一状态。
- 开关、开始录音等操作等待 ESP32 确认后才更新为成功；显示设备确认状态，不能把本地按钮变色当作动作已到达。
- 一次只有一个浏览器连接拥有控制权，其他页面可查看状态，不能混入方向或音频指令。原连接实际断开后允许新连接重新认领，不自动恢复 INMP441。
- 显式停止按钮会取消当前网页语音及其待返回动作，避免随后到达的 AI 回复重新启动运动。

## 4. 本地 HTTPS 与证书

保留 HTTP 配网入口及证书下载指引，在 HTTPS 提供遥控页面和同源 WSS。HTTP 页面不承诺具备录音能力，自动弹出的联网认证窗口引导到完整浏览器。

- 使用 ESP-IDF `esp_https_server`，启用 WebSocket 支持；复用现有 AP 和单一 Wi-Fi 驱动。
- 主要入口固定为 `https://192.168.4.1`，服务器证书的 Subject Alternative Name 包含 IP `192.168.4.1`。
- 提供本地证书生成工具：生成专用根 CA 和服务器证书，服务器证书有效期采用 90 天；支持使用原 CA 续签服务器证书，避免每次重新安装根证书。
- 根 CA 私钥仅留在本机，绝不写入固件、下载接口或源码提交。服务器私钥存本地忽略目录，通过构建时嵌入；不输出私钥内容。浏览器仅下载公开根证书。
- 证书生成工具不自动安装系统根证书，不修改手机或电脑浏览器安全策略；安装和信任由用户完成。
- 配套说明覆盖 Windows Chrome、安卓证书安装和 iPhone 证书描述文件安装及“启用完全信任”。显示证书指纹和有效期，便于核对。
- 本次以连接设备热点访问固定 IP 为支持路径，不承诺任意路由器分配的 STA IP 都能通过证书验证；不新增互联网转发或远程公网控制。
- 若证书缺失或 HTTPS 启动失败，页面明确显示语音不可用，HTTP 配网仍可使用，不回退为假成功的录音入口。

## 5. 热点生命周期

新增仅针对本功能的常开配置。已有普通板型及关闭本功能的构建保留原有行为。

- 在 Wi-Fi 初始化后启动 AP、网页及 HTTPS，再按原路径判断是否有已保存 Wi-Fi 并启动 STA。
- AP 已运行不等于设备正等待配网。区分“AP 服务存在”和“配网流程中”，避免普通启动一直停在 WifiConfiguring、阻止平台激活或自动聆听。
- 支持 AP+STA，保留原网络重试、令牌、OTA 和平台配置策略。
- 常开模式下激活成功只更新网页状态，不再退出 AP；`/exit` 与旧的延迟关闭任务均不能关闭常开热点。
- 网络断开时 AP 及本地按键入口保持运行；平台不可用时明确拒绝开始语音，方向按钮仍通过本地 UART 工作。

## 6. 独占接管与延迟回复隔离

由 Application 主任务管理控制来源；网络回调只投递有容量限制的事件，不直接操作 UART、协议对象或音频来源。

- 遥控关闭：INMP441 使用既有连续监听和严格动作 JSON 路径；网页动作、录音请求均拒绝。
- 开启遥控：暂停本地语音处理与唤醒上传，提升控制代际，清理麦克风待编码/待发送数据、未完成动作回复，关闭旧平台音频会话。完成后确认接管，保持 AP 及 STA。
- 网页按键直接映射现有运动位，使用现有 `AA 55 STATE CRC8` 输出；不经 AI，不改 STM32 协议，不新增发射按钮。
- 开始网页录音时使用新音频会话及原协议的手动结束模式，确认平台就绪后才接受音频。按键动作或显式停止优先于待返回的网页语音动作，并使该语音轮次失效。
- 关闭遥控：发送全零停止状态，结束网页录音，提升代际、清空相关队列和回复，关闭网页音频会话，再沿用原路径恢复 INMP441。
- 代际必须贯穿回调接收、主任务事件、PCM 编码任务和编码完成包；只清空队列无法阻止正在编码的旧包重新入队。
- 协议回调绑定音频通道实例/连接代际，旧连接的 JSON、关闭事件和错误事件不得改变新来源。主任务执行已排队事件时再次校验代际，不能仅在网络回调时检查。
- 不依赖 SendAbortSpeaking 成功来隔离旧回复；关闭旧音频通道并启用新连接边界，沿用平台现有连接参数。
- 网页语音仍只接受完整合法五字段 JSON，保留转向别名及一次回复只执行一次的规则。非 JSON、识别文字和 STT 都不能变成语音动作依据。

## 7. 浏览器到 ESP32 的音频流程

浏览器麦克风 → AudioWorklet 采集 → 连续重采样到 16 kHz/单声道 → PCM16 little-endian → 同源 WSS → 有界缓冲/校验 → 60 ms 帧 → 现有 Opus 编码器 → 原平台链路。

- 根据实际 AudioContext 采样率处理 44.1 kHz、48 kHz 等输入，跨采集块保留重采样状态，降采样进行低通处理，不能只把设备采样率字段标成 16 kHz。
- 不上传 MediaRecorder 默认产生的 WebM/AAC/MP4 容器，避免 ESP32 另行解码和不同浏览器格式不兼容。
- 控制消息描述固定音频版本、采样率、声道、编码、录音代际和帧序号。只有当前控制连接及有效录音代际能提交二进制音频。
- 以 960 样本为完整帧；ESP32 支持完整帧和结束时不足一帧的尾部样本。正常结束时对非空尾帧补零后编码，无样本不生成虚假音频帧。
- 正常松开说话时，先提交剩余采样，再发结束标记；ESP32 等该轮 PCM 编码及 Opus 发送完成后才 SendStopListening，避免截掉最后几个字。
- 取消、失权、格式错误或开关切换时丢弃尾部，不当成正常结束提交。
- 限制控制消息、二进制帧、PCM 缓冲和待发送数据的大小；沿用现有两帧编码队列容量，通过非阻塞提交和确认控制流量，避免 HTTP/WSS 回调阻塞等待编码。
- 正确处理 WebSocket 分片、长度及音频字节对齐，超限或格式不符明确拒绝，不按收到的数据声明任意分配内存。
- 网页检查 bufferedAmount 并结合设备确认限制在途数据。拥塞导致该句无法完整接收时报告错误并取消该轮，不悄悄丢字后继续提交。
- Opus 编码仍只由已有编码任务执行；网络线程不同时调用同一个编码器，不另开竞争编码任务。
- 浏览器音频不经过 INMP441 专用 I²S 读取和硬件输入处理；保留系统提示音及既有下行控制语音忽略策略。

## 8. 模块与预计改动位置

| 模块 | 职责与位置 |
| --- | --- |
| 遥控业务 | `main/car/` 新增控制权/音频分帧模块，扩展 `car_controller` 的网页动作入口 |
| 应用接入 | `main/application.h/.cc` 接管事件、会话代际、音频开始结束、恢复本地监听 |
| 音频服务 | `main/audio/audio_service.h/.cc` 非阻塞外部 PCM 提交、源代际清理、发送完成边界 |
| 平台协议 | `main/protocols/` 必要的连接代际回调过滤，不改平台协议或认证参数 |
| 热点管理 | `main/boards/common/wifi_board.cc`、本地 `third_party/esp-wifi-connect/` 常开 AP/STA 生命周期 |
| 网页服务 | 本地配网组件中注册遥控页面、HTTPS/WSS 与公开根证书下载，保留已有页面入口 |
| 页面资源 | 本地配网组件 `assets/` 中的 HTML、脚本及 AudioWorklet |
| 配置 | `main/Kconfig.projbuild`、相关 CMake、PlatformIO defaults 及当前生成配置 |
| 证书工具和说明 | `scripts/` 新增生成/续签工具，`.gitignore` 忽略证书私钥，`docs/` 增加使用说明 |

不修改相邻 ESP32-S3、stm32_car、stm32_motion 工程。仅修改本地维护的 esp-wifi-connect，不修改 managed_components 缓存。

## 9. 验证与完成条件

- 电脑端业务测试：开关切换、非法来源拒绝、旧事件/旧编码任务隔离、方向与停止帧、音频帧边界/尾帧/格式/溢出，以及结束前完成发送。
- 前端检查：手机与桌面尺寸、五个按钮始终可见、触摸取消/失焦、键盘释放、权限拒绝、非安全环境、连接失败和重复点击。
- 音频算法测试：44.1/48 kHz 到 16 kHz 的连续分块重采样、字节序、样本数和幅值范围，不仅检查输出文件存在。
- 证书验证：链、IP SAN、有效期和指纹正确；根私钥未嵌入固件，任何网页/API 均不提供私钥或平台 token。
- 执行现有小车及串口测试，新增必要的遥控/音频测试；完成 `pio run -e esp32s3`，记录真实 RAM、程序占用和构建结果。
- 真机检查单独记录：普通已配网重启仍开 AP；激活后 AP 保留；AP+STA 与平台连续联网；安卓 Chrome、iPhone Safari、电脑 Chrome 实际授权录音；UART 收帧和运动。
- 软件检查通过只能证明软件与构建结果，不宣称未执行的手机兼容、音频识别、无线并发、UART 电气和实车测试已通过。未获得本轮授权不烧录、不提交、不推送。

## 10. 范围边界

- 不新增周期动作心跳、运动计时、STM32 ACK、超时看门狗、断网自动停机或网络恢复策略；页面尽力发送的释放/失焦停止不能替代断线看门狗。
- 浏览器连接丢失时释放该连接身份并取消未完成音频，遥控接管状态保持，等待显式关闭/重新认领；不擅自恢复 INMP441，也不对运动状态增加未确认的断线规则。
- 不新增 GPIO、改变 UART 115200 和 TX17/RX21、不配置尚未确认的业务 LED。
- 本机根证书安装是用户操作；不会通过工具静默写入系统信任库。
- 当前工作目录不属于 Git 仓库，因此本轮不执行 Git 暂存、提交或推送，也不因设计文件变更询问是否提交。
