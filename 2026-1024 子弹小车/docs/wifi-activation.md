# 配网页显示灵矽激活码

当前 PlatformIO 配置另外开启了网页遥控。该模式覆盖本文的“激活后关闭热点”规则：热点上电常开，成功页提供遥控及证书入口，激活后保留 AP。操作与证书安装见 [网页遥控器](web-remote.md)。关闭 `CAR_WEB_REMOTE` 后仍使用下述原流程。

当前 PlatformIO 环境启用 `CONFIG_WIFI_ACTIVATION_PORTAL=y`。其他配置默认关闭此功能，保持原配网成功后退出热点的流程。

## 使用流程

1. 手机连接设备的 XiaoQiu 热点，打开 `http://192.168.4.1`，填写路由器 Wi-Fi。
2. 配网成功后自动进入成功页。热点和网页保留，设备通过同一个 Wi-Fi 驱动连接路由器，随后走原平台激活流程。
3. 页面显示连接状态、平台提示和激活码。激活码保留前导零，可点击复制；不需要扬声器才能读取。
4. 使用移动网络或另一台设备在灵矽平台完成绑定。设备热点只负责本地配网与显示状态，不提供互联网转发。
5. 设备取得平台连接配置后显示绑定成功，清除页面激活码并关闭热点。路由器连接保留，设备继续原语音会话流程。

页面每 1.5 秒刷新状态；看到成功后约 1.5 秒请求退出。设备端另有 5 秒关闭兜底，即使浏览器关闭，也会收起本次已完成激活的热点。延迟退出任务绑定配网代际，不能关闭后来重新开启的热点。

若平台连接失败，页面显示错误状态并继续读取设备状态，不擅自增加平台重试次数。等待激活时不允许在旧配网页重复修改 Wi-Fi，以免打断正在进行的连接。

此功能服务于本次热点配网流程。已有 Wi-Fi 的普通重启继续按原方式直连路由器，不会为了显示激活码主动重新开启热点；断电、OTA 重启后的热点恢复仍沿用原工程方式。

## 维护方式

- 配网组件基于 78/esp-wifi-connect 3.0.2，维护于 `third_party/esp-wifi-connect/`，由 `main/idf_component.yml` 的 override_path 引用；不编辑下载缓存。
- `/activation/status` 只返回 enabled、state、code、message，禁止返回 Wi-Fi 密码、token 或完整 OTA 响应。状态只保留在内存，接口禁用缓存。
- `/activation/start` 只在已保存 Wi-Fi 后启动原 WifiStation，重复请求不会重复启动。等待期间暂停 AP 扫描，连接仍由原 Station 实现负责。
- 激活码来自原 ShowActivationCode 入口；成功必须同时满足不再要求激活码/挑战且已取得 MQTT 或 WebSocket 配置，不能仅凭激活线程结束误报成功。
- AP 关闭时保留 STA；避免触发新的 Wi-Fi 连接和连接超时定时器。
- 本次不修改 WSS、令牌存储、平台鉴权或重试策略。
