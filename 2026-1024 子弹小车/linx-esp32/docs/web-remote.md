# 网页遥控器

## 使用

1. 按原工程方式烧录新固件。热点每次上电开启，包括已有 Wi-Fi 配置及激活完成后的启动。
2. 手机或电脑连接 `XiaoQiu-xxxx` 热点。该热点提供本地页面，不转发互联网；ESP32 另通过已配置的路由器访问灵矽。
3. 配网和激活仅使用 `http://192.168.4.1/`；该页面没有遥控入口。首次安装证书可直接使用本机 `.local-remote-tls/car-root-ca.cer` 公开文件。
4. 在完整浏览器中打开 `https://192.168.4.1/`。安卓、iPhone、电脑都显示五个控制按钮及遥控开关。不要使用系统自动弹出的联网认证小窗口录音。
5. 点击“开启遥控”，等待设备确认独占接管。INMP441 的处理和上传暂停，原音频队列及待返回语音动作被隔离。
6. 按住前进、后退、左转、右转移动，松开停止；停止按钮始终显示。电脑还支持 WASD、方向键，空格停止。
7. 取得遥控权后即可点击“开始收听”，浏览器随即弹出麦克风授权，首次需选择允许；页面提示“正在申请麦克风权限”后等待设备确认 realtime 会话，再连续上传，可连续说多句话，句间不发送结束标记。若证书未受信任、浏览器不支持录音或灵矽平台尚未就绪，页面显示对应原因，方向按钮仍可使用。再次点击“关闭收听”才结束采集和上传；关闭后网页仍独占，INMP441 不恢复。
8. 点击“关闭遥控”：先发送停止，取消网页语音及待返回动作，再恢复 INMP441。网页初次加载不会自动接管。

方向按钮和停止优先于尚未完成的网页语音，但不关闭手机采音；旧 AI 回复不能覆盖手动操作，下一个 STT 输入边界才重新允许 AI 动作。左右按钮和键盘的映射已互换，AI JSON 字段含义不变。语音只能通过原有严格动作 JSON 执行，识别文字不是动作依据。方向按钮直接复用原 UART 状态帧，不必等待 AI。

控制端口同一时间只接纳一个浏览器连接，包括尚未开启总开关的页面；切换设备前先关闭原遥控页面。连接丢失后页面禁用按钮；点击重新连接、读取状态，再重新接管。丢失网页连接不会擅自切回 INMP441，也没有新增断线运动停机、心跳或看门狗。

## 单次发射

开启网页独占遥控后，点击“发射一次 · 蓄力重炮”发送 `fire` 请求。ESP32 在输出锁内保留当前四个运动位并置 bit4，通过原 `AA 55 STATE CRC8` 帧转发 STM32；方向请求仍只接受原四个方向和停止。无需云端平台就绪，不关闭网页收听，不等待应用主任务的云端发送。

STM32 按 `PB10、PB1、PA7、PA6、PA5、PA4、PA3、PA2、PA1、PA0` 的低有效灯排播放单次灯效：3.4 秒蓄积、0.8 秒压缩、加速出膛和余波，总计 6.4 秒内结束，全部置高熄灭。播放中重复发射忽略；方向、停止、后续 fire=off 不中断该灯效。语音仍通过严格五字段 JSON 的 `fire:"on"` 触发。

网页“指令已发送”只表示 ESP32 已处理转发请求，不代表 STM32 已收帧或灯效完成；没有新增 STM32 回传协议。

## 首次安装证书

仅安装当前这套固件对应的公开根证书，先与生成工具输出的 SHA256 指纹核对。安装由用户完成，工具不会修改系统信任库。

- **Windows Chrome**：打开 `car-root-ca.cer` 或下载的 `.crt`，使用“安装证书”，选择当前用户的“受信任的根证书颁发机构”，关闭并重新打开遥控页面。
- **安卓 Chrome**：在手机设置的证书安装入口选择“CA 证书”并导入。不同品牌菜单位置不同，通常在安全／加密与凭据／安装证书。完成后重新打开 HTTPS 页面并允许麦克风。
- **iPhone**：在 Safari 下载根证书，进入设置中的“已下载描述文件”或“通用 → VPN 与设备管理”安装；再进入“通用 → 关于本机 → 证书信任设置”，对该根证书启用完全信任。之后重新用 Safari 打开 HTTPS 页面。

安装文件也可从本机 `.local-remote-tls/car-root-ca.cer` 获取。不要把 `root-ca-key.pem` 或 `server-key.pem` 复制到手机或分享。

本地入口固定为 `192.168.4.1`。证书包含这个 IP，不覆盖任意路由器分配的 STA 地址。仅点击浏览器证书警告页的“继续”不能保证麦克风接口可用。

官方说明：[浏览器录音](https://developer.mozilla.org/en-US/docs/Web/API/MediaDevices/getUserMedia)、[iPhone 证书信任](https://support.apple.com/en-gb/102390)。手机系统菜单和实际浏览器兼容性仍需实机确认。

## 本机证书生成、续签和构建

在 `linx-esp32` 目录执行：

```powershell
$carPython = "$env:USERPROFILE\.platformio\penv\Scripts\python.exe"
& $carPython -m pip install --target .cache/remote-cert-tools -r requirements-remote-certificates.txt
$env:PYTHONPATH = (Resolve-Path .cache/remote-cert-tools).Path
& $carPython scripts/remote_certificates.py
& "$env:USERPROFILE\.platformio\penv\Scripts\pio.exe" run -e esp32s3
```

根 CA 和服务器证书保存在 `.local-remote-tls/`，整个目录已忽略。构建只嵌入服务器证书、服务器私钥及公开根证书，根 CA 私钥从不参与固件构建。首次生成后不要无故更换根 CA。

服务器证书有效期 90 天；续签沿用原根 CA，然后重新构建、烧录即可，无需再次安装同一根 CA：

```powershell
& $carPython scripts/remote_certificates.py --renew
& "$env:USERPROFILE\.platformio\penv\Scripts\pio.exe" run -e esp32s3
```

源码不携带通用私钥，新机器构建前需生成自己的证书。缺少证书时构建会明确停止，不生成无法验证的假录音页面。HTTPS 运行时启动失败会记录错误，原 HTTP 配网页仍保留。

## 音频与控制实现

- 浏览器 AudioWorklet 使用实际采样率，连续分块低通重采样到 16 kHz 单声道 PCM16，小端编码；不使用浏览器各异的 WebM/AAC 录音容器。
- 页面使用 HTTPS 443，控制与音频使用独立 WSS 8443；控制端口在分配 TLS 内存前拒绝额外连接。刷新页面的握手不占用已有控制服务任务。
- WSS 二进制消息由 12 字节小端头和最多 1920 字节 PCM 组成。头依次为请求编号、录音编号、音频序号，每项 uint32；录音编号绑定 start 请求。
- ESP32 拒绝不匹配的来源、录音编号、顺序、奇数字节、超长消息和缓冲超限。WebSocket 分片在 1932 字节总上限内合并。
- 960 个样本组成一个 60 ms 帧，正常结束的非空尾帧补零；取消则丢弃。复用 AudioService 的原 Opus 编码任务，不在网络回调里阻塞编码。
- 编码队列最多两帧，网页最多缓存四帧并逐包等待设备接收确认。拥塞、编码或发送失败会取消该句并提示，不悄悄漏字后继续提交。
- end 仅在用户关闭收听时发送；排空 PCM/Opus 后发送原平台 SendStopListening，重置该会话和待返回动作，但保持网页接管。离开页面、连接失败或音频拥塞也会释放录音并提示；页面失焦不主动关闭收听。手机系统后台限制仍可能暂停浏览器采音。
- 来源切换提升代际，清理队列；正在编码的旧任务返回后也被丢弃。平台回调和已排队的主任务事件都校验连接／控制代际。
- 新来源的第一帧由编码任务重置 Opus 状态；恢复 AFE 本地处理时，旧的不足一帧 PCM 由处理任务按代际清理，不跨来源拼接。
- WSS 平台关闭旧连接后建立新连接；若平台使用 MQTT，其控制连接也随输入来源重建，并要求 TTS/STT 带匹配 session_id，拒绝无法区分来源的旧事件。沿用原认证和异常重试策略。
- 本功能由 `CONFIG_CAR_WEB_REMOTE` 隔离，默认关闭，当前 PlatformIO 配置开启；依赖小车控制、热点配网和非串口文字测试模式，并启用激活页面、HTTPS/WSS。
- 当前 PlatformIO socket 上限仍为 20。HTTP 配网最多三个、HTTPS 页面最多三个、控制服务最多两个 socket（第二个在 TLS 握手前拒绝），控制连接不被 LRU 淘汰。握手超时复用原接收等待的 5 秒上限；TLS 内存沿用既有 PSRAM 配置，动态峰值待实测。
- UART 仍是 115200、TX17/RX21、`AA 55 STATE CRC8`。全零停止也发送。日志和网页确认代表 ESP32 已处理指令，不代表 STM32 已收到或实车已运动。

## 流畅度与故障边界（2026-10-24 修订）

- 首屏内联脚本并预先 gzip，CSP 用脚本哈希；不引用在线字体、框架、图标或 CDN。资源带 ETag，未变化时返回 304；音频工作模块按内容版本缓存。没有在 ESP32 上实时压缩。
- 不再嵌入重复的原始 HTML/页面脚本，保留压缩首屏及不支持 gzip 时的明文回退。PCM 成功确认仅返回 id/ok；网页只在控制状态变化时更新按钮，收听期间不轮询状态。
- 松开方向键立即写入停止，不等待上一条 ACK。已有控制权的方向/停止直接从控制服务下发 UART，应用主任务在云端连接或发送期间仍可响应。总开关关闭也先走该停止路径，再由主任务清理并交还板载语音。
- CarController 的短输出互斥区串行化 AI 和网页输出；回复解析仍由应用主任务处理。手动操作使已排队的旧回调失效，并屏蔽旧轮 AI 输出，下一句输入边界才解除。
- AFE 输出遇编码队列满不再无限等待，而是标记上传失败、继续消费 AFE；主任务取消受影响的会话并清理旧队列。不会把丢帧后的不完整语音继续作为正常命令上传。本地会话取消后沿用原后续恢复行为；网页故障仍保留独占。
- TLS 握手错误仍可能由证书不信任、客户端关闭预连接、内存或无线链路引起。代码已隔离握手阻塞、减少连接和页面传输；未接硬件日志前不能声称所有错误码已消失。
- 实机验收：连接热点→开启遥控→连续前后左右/停止；另开页面触发握手时检查 UART 延迟；连续手机语音多句→关收听保持独占→关总开关先停止再恢复 INMP441；分别在安卓 Chrome、iPhone Safari 和电脑 Chrome 验证。


### 手机音频短时积压修复

- 手机 PCM 上传由逐帧等待改为最多三帧在途，网页待发最多八帧；ESP32 外部 PCM 编码队列最多八帧，本地 AFE 队列保持原上限。全部队列仍有界，持续拥塞明确取消，不静默丢帧。
- 取消收听时隔离旧请求集合，旧确认不能占用新录音的窗口；停止控制不等待音频确认。


### 常开热点 DNS 修复（2026-10-24）

用户实机日志出现连续 DNS 重定向和本地 HTTPS 握手失败。CAR_WEB_REMOTE 模式下 DNS 改为返回 NXDOMAIN，不再把手机访问的所有外站域名映射到 192.168.4.1；普通配网模式保留原重定向。遥控和配网均直接输入 IP 访问，遥控热点不再依赖自动弹出配网窗口。手机可能缓存旧 DNS 结果，更新后断开再连接热点。新增 PCM 拒绝日志用于区分音频会话/顺序/队列故障；日志中的 TCP receive failed 可能是主动关闭连接后的结果，不能单凭该行判定云端故障。尚未实机确认修复效果。


### 手机音频与云端发送并行（2026-10-24）

- 用户要求将云端发送与手机处理分离。新增 remote_uplink 独立任务，只负责网页音频的云端 SendAudio；手机 PCM 校验、拼帧留在应用任务，Opus 沿用原独立编码任务。本地语音原发送路径保持原状。
- 发送任务一次持有一帧，不另建无界队列，完成后唤醒主任务继续派发。结束收听同时检查编码/待发队列和在途发送，最后一帧返回前不发送 listen.stop。
- 协议共享所有权保证任务在途时对象存活；发送与连接打开/关闭/重置以会话锁串行化，发送前在锁内核对连接代际，旧帧不能进入新连接。取消并不强行中断底层正在进行的网络写入，切换会话仍可能等待该帧；正常采音处理不再执行云端写入。
- 软件验证只做修改源文件的定向编译和关闭收听等待在途帧的流程测试；未重新生成固件或实机测量延迟。


### 麦克风授权先于平台就绪（2026-10-25）

- 用户实机现象：网页已独占接管，但“开始收听”在点击前被禁用，浏览器因此没有机会弹出麦克风授权。
- 修订后仅在本页未取得遥控权且未在录音时禁用该按钮；取得控制权后即可点击，不再由平台就绪、安全上下文或录音能力在点击前拦截。
- 点击时页面先校验安全上下文、`navigator.mediaDevices.getUserMedia` 与 `AudioWorkletNode`，再申请麦克风；弹窗期间提示“正在申请麦克风权限”，失败原因写入状态栏和收听提示，包括证书未受信任、浏览器不支持录音、平台尚未就绪。
- 服务端 `start` 的平台与 Wi-Fi 检查保留并继续生效，未放宽为无平台录音；设备返回“平台尚未就绪，方向按钮仍可使用”，网页只负责把原因显示出来。
- 软件检查：`node test/web/remote_ui.test.cjs` 覆盖平台未就绪时仍可点击、实际发起授权请求、展示原因，以及非安全上下文提示；网页重新打包为 16,671 字节（gzip 6,228 字节）并嵌入固件。
- 本轮固件构建成功：静态 RAM 70,012 字节（21.4%），应用 2,701,003 字节（65.4%），已更新 `.pio/build/esp32s3/firmware.bin`；未烧录。
- 尚未实机验证：安卓 Chrome、iPhone Safari、电脑 Chrome 的真实授权弹窗；点过证书警告“继续访问”但根证书未受信任时的实际表现；平台未就绪时授权后关闭的交互。
