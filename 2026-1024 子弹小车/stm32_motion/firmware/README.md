# STM32F103 单次蓄力重炮与轮速调试固件

日期：2026-10-25。适用芯片：STM32F103C8，8MHz 外部晶振、72MHz 系统时钟。

| 动作 | 左侧 PWM | 右侧 PWM |
| --- | --- | --- |
| 前进直行 | +80% | +80% |
| 后退直行 | -70% | -70% |
| 左转 / 前进+左转 | +56% | +70% |
| 右转 / 前进+右转 | +70% | +56% |
| 后退+左转 | -70% | -56% |
| 后退+右转 | -56% | -70% |
| 停止 / 矛盾动作 | 0 | 0 |

bit4=1 的合法状态帧播放一次蓄力重炮灯效：灯排 PB10、PB1、PA7、PA6、PA5、PA4、PA3、PA2、PA1、PA0 低有效，PB10 为红色核心跨三轮升亮；三轮蓄力后反向 50ms 逐颗发射，6.4 秒内结束并全部熄灭。PB0 蜂鸣器高有效，发射开始时输出两次 50ms 高脉冲。忙时忽略重复发射，不排队；方向、停止和 fire=off 不中断已开始的灯效。TIM2 20kHz 中断提供 625Hz/32 级软件 PWM，电机仍使用 TIM4 PB6～PB9。

## 烧录

- `firmware.bin`：写入地址 `0x08000000`，文件大小 4148 字节。
- `firmware.hex`：Intel HEX 格式，自带地址信息。
- BOOT0、串口隔离与下载方式详见[工程说明](../README.md)。烧录后先悬空测试方向、左右转和停止。

## 验证状态

PlatformIO release 编译通过，Flash 4148 / 65536 字节，RAM 1728 / 20480 字节。
ARM 模拟逻辑测试通过，覆盖 CRC、全部状态、流式恢复、运动映射、UART 队列，以及灯序、全亮/全灭、PB0 双脉冲、引脚隔离与时钟回绕。
用户已上机烧录验证（2026-10-25）：蓄力重炮灯效亮度与节奏、PB0 双响、前进/后退/转向/停止均正常；实际亮度与电气时序以这次实车结果为准。
