# PM

## 子弹小车

完整项目见 [2026-1024 子弹小车](2026-1024%20子弹小车/)。

架构说明见 [子弹小车架构说明](子弹小车架构说明.md)。

视频演示地址：[https://www.bilibili.com/video/BV1hnHT6tEHg](https://www.bilibili.com/video/BV1hnHT6tEHg)

使用方式：在 VS Code 中安装 PlatformIO IDE 插件，将 ESP32、STM32 固件分别烧录到对应开发板。完成接线、首次配网和平台绑定后，插电即可控制使用。首次使用网页语音时，请按 [网页控制说明](2026-1024%20子弹小车/linx-esp32/docs/web-remote.md) 完成证书信任和麦克风授权。

做了三个产品决策：

1. **简化控制动作**：放弃“往前开三米，再左转……”等复杂控制，只保留上、下、左、右、停止、发射子弹六个动作。
2. **做内网控制器**：解决收音问题。
3. **使用激光子弹**：发射子弹的方案选择激光子弹。
