## 子弹小车

完整项目见 [2026-1024 子弹小车](2026-1024%20子弹小车/)。

视频演示地址：[https://www.bilibili.com/video/BV1hnHT6tEHg](https://www.bilibili.com/video/BV1hnHT6tEHg)

1. **简化控制动作**：放弃“往前开三米，再左转……”等复杂控制，只保留上、下、左、右、停止、发射子弹六个动作。
2. **做内网控制器**：解决收音问题。
3. **使用激光子弹**：发射子弹的方案选择激光子弹。
