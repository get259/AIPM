# AIPM

## 语音控制子弹小车

基于 ESP32-S3、STM32F103 与灵矽平台的智能硬件项目。通过手机网页收音，用语音控制小车移动和发射，也可以直接使用网页按键遥控。

**新增 JEV 模型层**：基于灵矽模型能力自行封装，用于本项目的语音交互。模型返回动作 JSON，由 ESP32 校验并转换为小车指令，再交给 STM32 执行。

### 已实现功能

- **六种动作**：前进、后退、左转、右转、停止、发射子弹。
- **持续语音控制**：点击开始收听后可连续说多句话，完整动作 JSON 校验通过即下发。
- **网页遥控**：方向键按住移动、松开停止；电脑支持 WASD、方向键和空格停止，并提供独立发射按钮。
- **开火联动**：STM32 控制蓄力灯效、蜂鸣器与 PB5 舵机，配合完成发射动作。

### 三个产品决策

1. **选用两个主控芯片**：ESP32 负责联网、语音和平台交互；STM32 负责电机、灯效、蜂鸣器及舵机，方便扩展执行端功能。
2. **简化控制动作**：放弃“往前开三米，再左转……”等复杂组合，只保留六个基础动作，降低交互与实现成本。
3. **做内网控制器**：通过手机麦克风收音，改善车载麦克风受距离和电机噪声影响的问题，同时提供按键遥控入口。

### 架构与代码

语音链路：**手机网页 → WSS → ESP32 → 灵矽 / JEV 模型层 → 动作 JSON → ESP32 → UART → STM32**。

| 部分 | 主要职责 | 代码位置 |
| --- | --- | --- |
| ESP32 | Wi-Fi、平台连接、音频采集与编码、动作 JSON 校验 | [linx-esp32](2026-1024%20子弹小车/linx-esp32/) |
| STM32 | 接收动作指令，控制电机与开火联动 | [stm32_motion](2026-1024%20子弹小车/stm32_motion/) |
| 板间通信 | UART 传输动作状态，使用四字节帧及 CRC 校验 | ESP32 的 `main/car/`、STM32 的 `src/` |
| 网页控制器 | 手机收音、方向按键、控制权切换 | [main/car/web](2026-1024%20子弹小车/linx-esp32/main/car/web/) |

网页按键直接经 ESP32 下发指令；语音控制需要 ESP32 联网并连接灵矽平台。网页取得控制权后暂停车载麦克风，关闭遥控后恢复。

### 使用方式

1. 在 VS Code 中安装 **PlatformIO IDE** 插件，分别打开 `linx-esp32/`、`stm32_motion/`，将固件烧录到对应开发板。
2. 按接线说明连接两块板、电机和外设，完成首次配网及灵矽平台绑定。
3. 手机或电脑连接小车热点，打开 **<https://192.168.4.1/>**。首次使用网页语音，需信任本地证书并允许麦克风访问。
4. 点击“开启遥控”，使用方向按键；点击“开始收听”后即可发出语音指令。完成首次配置后，插电即可使用。
